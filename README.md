## 🔄 更新原则

- 项目优先级、卡点或进度有变化 → 更新 `02-PROJECTS.md`（同步顶部日期）
- 新增好用的触发词、沟通规则或踩坑禁忌 → 更新 `03-PREFERENCES.md`
- 门店业务或工具阵容有调整 → 更新 `01-ABOUT-ME.md`
- 日常对话中直接说 **“更新我的档案”**，即可让 AI 自动整理需要修改的内容
