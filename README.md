# 涤生的 AI 共享档案 🧠

> > 这是我的个人 AI 档案仓库，让所有 AI（Grokbot / Kimi / GPT / 智谱 / DeepSeek / Codex 等）都能快速认识我，无需每次重复介绍。
## 📚 档案结构

| 文件 | 内容 |
|---|---|
| [01-ABOUT-ME.md](./01-ABOUT-ME.md) | 关于我：身份、背景、联系方式 |
| [02-PROJECTS.md](./02-PROJECTS.md) | 当前项目：正在推进的工作 |
| [03-PREFERENCES.md](./03-PREFERENCES.md) | 使用偏好：沟通风格、禁忌 |

## 🤖 AI 接入提示词

将以下内容发送给任何 AI，它就能快速了解我：

\`\`\`
请先完整阅读以下档案，了解我是谁、我在做什么、我喜欢怎样被帮助：
https://github.com/di-sheng123/my-ai-memory

读取完成后，用一句话确认你已理解我的身份和偏好，然后我们正式开始对话。
\`\`\`

## 🔄 更新原则

- 项目变化时更新 `02-PROJECTS.md`
- 偏好变化时更新 `03-PREFERENCES.md`
- 身份信息长期稳定，很少改 `01-ABOUT-ME.md`

## 🛡️ 安全原则

本仓库**绝不存储**：密码、Token、API Key、验证码、身份证、银行卡等敏感信息。
